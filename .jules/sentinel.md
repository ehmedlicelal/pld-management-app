## 2024-04-03 - [CRITICAL] Removed x-admin-password Authentication Backdoor
**Vulnerability:** A hardcoded bypass using the `x-admin-password` HTTP header allowed anyone who obtained the `VITE_ADMIN_PASSWORD` (or `ADMIN_PASSWORD`) to gain full admin access without any valid JWT token. This completely circumvented the application's intended role-based access control and JWT authentication mechanisms.
**Learning:** Hardcoded authentication bypasses ("backdoors"), even if intended for administrative convenience, pose a critical security risk. They break the core trust model, are difficult to manage, and if leaked, give attackers unrestricted access to the entire application state. Authentication should uniformly rely on robust, centralized mechanisms like JWTs.
**Prevention:** Never use static strings or special headers to bypass authentication logic. Ensure all API routes, especially sensitive admin routes, enforce uniform and strict token validation. Implement role-based authorization directly tied to the token's decoded user identity (`req.user.role`).

## 2025-02-12 - [Critical] Hardcoded Admin Backdoor Removal
**Vulnerability:** Found a hardcoded authentication bypass using the `x-admin-password` header in `server/utils/authMiddleware.js`. This allowed anyone with the value of `VITE_ADMIN_PASSWORD` (which could be exposed via the frontend, or easily brute-forced if weak) to gain full `admin` role privileges without needing a valid JWT. The client code (`client/src/api.js`) was also actively sending this header.
**Learning:** Environmental variables intended for the frontend (`VITE_ADMIN_PASSWORD`) were being used on the backend as a "secret" backdoor. The `x-admin-password` custom header bypassed the robust JWT verification logic entirely.
**Prevention:** Never use static passwords or secret strings to bypass standard authentication workflows (like JWT). Backend APIs should strictly enforce token-based verification without exception, and any administrative privileges must be securely embedded in the JWT payload and issued via proper authentication routes. Remove all front-end code that passes plain text passwords in request headers.
